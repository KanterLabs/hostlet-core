# Security Policy

## Supported Versions

Hostlet Core is pre-1.0. Security fixes are provided for the latest published
non-prerelease version only. Upgrade to the latest release before reporting an
issue when it is safe to do so.

## Reporting A Vulnerability

Do not open a public GitHub issue for a suspected vulnerability.

Email `support@hostlet.cloud` with the subject `Hostlet Core security report`.
Include the affected version, impact, reproduction steps, and any suggested
mitigation. Remove credentials, customer data, and unrelated private
information from the report.

Reports are handled on a best-effort basis; this project does not promise a
specific acknowledgement or remediation window. Please allow time to
investigate before public disclosure.
